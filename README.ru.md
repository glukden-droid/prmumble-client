# Клиент Mumble 1.5 для Project Reality

[English](README.md) | **Русский**

Клиент Mumble ветки 1.5 (по умолчанию `v1.5.939`) для Windows, собранный из
официальных исходников <https://github.com/mumble-voip/mumble> с патчем PR
(`patches/`). Заменяет PRMumble 1.3 из игры и работает с сервером prmumble
(<https://github.com/glukden-droid/prmumble>).

## Скачать

Готовые сборки — на странице [Releases](https://github.com/glukden-droid/prmumble-client/releases):
`PRMumble-portable-win64.zip` для игры и `.msi` (обычная установка Mumble).
Версия сборки — `1.5.939-prN` (N — номер сборки), она видна в «О программе»
и в файле `PRMumble\VERSION.txt`.

## Что добавляет патч

Всё, что лаунчер PR ждёт от PRMumble 1.3, подробности в `NOTES.md`:

- запуск лаунчером: `PRMumble.exe -m -z prmumble://ник@ip:порт`
  (схема `prmumble://`, ключ `-z` — свёрнутым);
- единственный плагин — ProjectReality (`plugins\ProjectReality.dll`, это
  Link-плагин Mumble под другим именем), он включён сам; позицию и identity
  (команда, отряд, ник, одноразовый пароль) лаунчер пишет в `MumbleLink`;
- своя позиция уходит на сервер в `UserState`, поле 20 (как в 1.3: когда
  сдвинулась больше чем на 10 по любой оси), чужие принимаются;
- HUD «кто говорит»: общая память `PRMumbleSharedData1`, формат как у 1.3;
- звук как в PRMumble 1.3: местный голос позиционный, до 75 м; рация отряда,
  SL и командира — на полной громкости на любом расстоянии;
- горячие клавиши (рация отряда, SL→SL, SL→командир, mute, deafen, громкость)
  хранятся и в реестре `HKCU\SOFTWARE\Project Reality\PR Mumble\shortcuts`
  в формате 1.3: лаунчер читает их для HUD и пишет туда свои назначения;
- нет вопроса «загрузить настройки из бэкапа» при каждом запуске (лаунчер
  всегда завершает клиент принудительно);
- поле 20 протокола = позиция, временные токены перенесены на 120 — как на сервере.

## Установка

1. Закройте игру и лаунчер.
2. Сохраните старую папку: переименуйте `mods\pr\bin\PRMumble` в `PRMumble_1.3`.
3. Распакуйте zip в `mods\pr\bin\` — должна получиться папка `PRMumble`.
   Файлы из скачанного архива Windows помечает как «из интернета» и при запуске
   пишет «неизвестный издатель» (сборка не подписана). Снимите метку один раз
   (PowerShell в папке `mods\pr\bin\PRMumble`):
   `Get-ChildItem -Recurse | Unblock-File`
4. Запустите лаунчер и зайдите на сервер — лаунчер сам запустит новый клиент.

Настройки, сертификат и база хранятся в `PRMumble\data\` (если папки `data`
нет, клиент работает как обычная установленная версия). Горячие клавиши PR
берутся из реестра, где их оставил PRMumble 1.3.

Язык интерфейса — как в Windows; сменить: Настройки → Пользовательский
интерфейс → Язык.

Откат: удалите `PRMumble` и верните имя `PRMumble_1.3` → `PRMumble`.

## Как собрать

1. GitHub → **Actions** → **Mumble client** → **Run workflow**.
2. При необходимости укажите другой тег Mumble (например, `v1.5.940`).
3. Скачайте артефакт:
   - `mumble-portable-<тег>-prN-win64` — папка `PRMumble`;
   - `mumble-installer-<тег>-prN-win64` — обычный установщик `.msi` (без портабл-режима).

## Проверка

- `scripts\hud_dump.py` — что клиент пишет в общую память HUD (на ПК с игрой);
- `scripts\pr_shortcuts.py` — горячие клавиши PR в реестре;
- `scripts\prmumble_cmdline.ps1` — как лаунчер запустил клиент.
